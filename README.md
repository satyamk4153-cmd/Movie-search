# 🎬 Movie Search App

A simple and user-friendly Movie Search Application that allows users to search for their favourite movies and explore movie details.

## 🚀 Features
- Search movies by name.
- Display movie details.
- User-friendly interface.
- Responsive design.
- Easy-to-use navigation.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Movie API

## 📂 Project Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/satyamk4153-cmd/Movie-search.git
   ```
2. Open the project folder.
3. Run `index.html` in your browser.
